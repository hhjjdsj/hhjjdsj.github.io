01 About

I study computer science at XJTLU Entrepreneur College (Taicang). My interests sit where operating systems, networks and data meet: how a TCP connection actually behaves when the receiver is slow, why a UDP stream silently loses frames, how a shuffle phase turns a word count into a distributed problem.

Outside coursework I enjoy low-level debugging — packet captures, sockets, processes — and I like writing tools that make behaviour measurable rather than guessable. Every result on this page comes from code I ran, not from a textbook.

04 Projects

CSI205TC · Q1

Video streaming over TCP and UDP

A Python streaming application that sends a 300-frame video as JPEG frames, once over TCP with length-prefixed framing and once over UDP with 1400-byte datagrams and frame reassembly. Captured with tshark and compared on latency, frame loss and packet overhead.

  • 0% frame loss on TCP
  • 31.7% loss on overloaded UDP
  • 94 zero-window events
  • Python
  • sockets
  • OpenCV
  • tshark

CSI205TC · Q2

This website

A hand-written static site — no framework, no CDN, three files — deployed with GitHub Pages. The interesting part is the network analysis behind it: DNS resolution, TCP handshake, TLS negotiation and HTTP response, measured with ping, tracert and Wireshark.

CSI205TC · Q3

MapReduce from scratch

A small MapReduce engine written in pure Python: parallel map workers emit (word, 1), a hash-based shuffle partitions the pairs across reducers, and each reducer sums its partition. No Hadoop and no Spark — the point is to show the model, not to hide it.

  • M map workers
  • R reducers
  • hash(key) % R partitioning
  • Python
  • multiprocessing
  • unittest

CSI205TC · Q4 / Q5

Hadoop vs Spark, and MLlib in practice

The same word-count workload implemented twice — Hadoop MapReduce and Apache Spark — to compare programming model, execution plan and performance, plus a complete Spark MLlib pipeline with feature engineering, training and evaluation.

  • 2 execution engines
  • 1 shared dataset
  • MLlib end-to-end
  • Hadoop
  • Spark
  • PySpark
